# 🌦️ Weather Forecast — Real-Time Weather App


**Beautiful weather forecasts with a sleek interface, animated visuals, and real-time **API** data.**

Weather Forecast is a lightweight weather application built using **HTML**, **CSS**, and JavaScript. It connects to a weather **API** to retrieve current weather conditions and display them through a clean, mobile-friendly interface.

The project focuses on making weather information easy to understand while delivering a polished experience through modern styling, weather icons, and an organized forecast layout.

## ✨ Features

- 🌍 **City-Based Weather Search** — Search for a city to retrieve its weather information.
- 🌡️ **Current Weather Conditions** — Display the current temperature and weather description.
- 🌧️ **Weather Visuals** — Show weather icons corresponding to the reported conditions.
- 📅 **Weather Details** — Present additional information such as humidity, atmospheric pressure, wind speed, and minimum and maximum temperatures, where supplied by the **API**.
- 🕒 **Hourly Forecast** — Display upcoming hourly weather conditions, if supported by the configured **API**.
- 🎨 **Sleek UI Design** — A modern interface with a dark blue color palette, clean typography, and organized weather cards.
- 📱 **Mobile-Friendly Layout** — Designed to present weather information clearly on a phone-sized screen.
- 🔄 **Live **API** Integration** — Retrieve up-to-date weather information through an external weather service.

## 📱 Interface Preview

The application features a compact weather dashboard with:

- A city search bar at the top.
- A current-weather card showing the temperature and conditions.
- Additional weather measurements.
- An hourly forecast section for upcoming conditions.

The design prioritizes readability and quick access to the most useful weather information.

## 🛠️ Built With

- **HTML5** — Application structure
- **CSS3** — Styling, layout, and visual presentation
- **JavaScript** — Search interactions, **API** requests, and dynamic content updates
- **Weather **API**** — Current weather data and forecast information

## ⚙️ How It Works

## The user enters a city name in the search field.
## JavaScript sends a request to the configured weather API.
## The application receives weather data for the requested location.
## The interface updates with the temperature, weather description, icons, and supported weather measurements.
## Forecast information is displayed when available from the API.

This workflow demonstrates how a frontend application can consume external **API** data and turn it into a user-friendly interface.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- An internet connection
- A valid **API** key if required by the configured weather service

### 1. Clone the repository

```bash
git clone [https://github.com/**YASHRAWAT**-**1611**/Weather-App-using-**API**.git](https://github.com/**YASHRAWAT**-**1611**/Weather-App-using-**API**.git)
```

### 2. Navigate to the project directory

```bash
cd Weather-App-using-**API**
```

### 3. Configure the weather API

Open `script.js` and identify the configured weather service and **API** request.

If the service requires an **API** key:

## Register with the weather API provider.
## Generate an API key.
## Configure the key according to the provider's instructions.

**Security note:** Avoid committing private **API** keys to a public repository. For a production application, use an appropriate backend or other secure configuration mechanism where necessary.

### 4. Launch the application

Open `index.html` in a browser, or use a local development server such as the Live Server extension in VS Code.

### 5. Search for a city

Enter a city name and check the returned weather information.
